## FYP — Main Branch

- `Main dashboard:` The primary dashboard code lives in the arslan branch.
- `archive/old-dashboard:` First dashboard implementation by Arslan. It was not adopted due to design issues; kept for reference.

### Notes

``` 
git checkout arslan
```

- Use `archive/old-dashboard` only for reference or to recover older components.
